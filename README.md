# 拉屎记录器 (Poop Recorder)

一个**移动端优先**的排便习惯记录工具：打卡、历史筛选、行内编辑、趋势图表与健康规律分析一应俱全。数据默认只存本地浏览器，可选通过坚果云 WebDAV 做端到端加密的跨设备同步；另有一个**默认关闭、自带密钥**的 AI 洞察功能，用你自己指定的大模型把统计数据总结成一段更容易读懂的解读。

在线地址：<https://ls.mofashi.ltd>

## 功能特性

### 记录

- **一键打卡**：打卡页中央大按钮，地点与备注可在「补充记录」抽屉里预先设好，到点按一下即可保存
- **补充记录**：底部抽屉里选地点（常用地点一键选择，或输入自定义地点）、填写备注、指定时间
- **历史列表**：按时间倒序展示，支持**行内编辑**（不跳页面直接改内容、地点、时间）
- **左滑删除 + 撤销**：左滑或点删除按钮均可，删除后有 4 秒撤销窗口，误删可一键找回
- **搜索**：按地点或备注模糊搜索（带防抖）
- **日期筛选**：自定义起止日期，或点击趋势图上的某一天直接筛出当天记录

### 分析

- **核心指标**：平均间隔时间、本周排便次数、最常用地点
- **规律洞察**：连续记录天数、本周 vs 上周对比、基于间隔波动的健康建议卡片
- **趋势图表**：可选**最近 7 / 14 / 30 / 90 天 / 全部**五档；支持点击柱状图联动筛选历史列表
- **AI 洞察**（可选，默认关闭）：用你自己指定的大模型服务，把上面这些统计结论总结成一段更容易读懂的解读。只发送聚合统计，不含备注原文；详见「数据与隐私」

### 数据

- **本地加密存储**：IndexedDB 为主存储，localStorage 仅作兜底；数据以 AES-GCM 加密后落盘
- **自动备份**：每次保存自动留档，最多保留 10 份，可从设置里直接恢复
- **手动导出**：JSON（完整备份，可回导）与 CSV（UTF-8 BOM，Excel 打开中文不乱码）
- **导入**：JSON 导入并**按 id 合并去重**，不会覆盖已有记录
- **坚果云同步**：手动上传/下载，云端数据用你的口令加密；**上传为合并操作**，本地与云端取并集，不会删掉云端已有记录

### 外观

- **深浅色主题**：跟随设置切换，深色下所有文字对比度均达到 WCAG AA
- **移动端优先**：底部导航 + 中央打卡按钮，触控目标全部 ≥ 44px（WCAG 2.5.5），无横向溢出，适配刘海屏安全区
- **无障碍**：语义化标签、`role="dialog"` / `aria-modal`、Toast 使用 `role="status"`、允许双指缩放（WCAG 1.4.4）

## 技术栈

| 类别 | 选型 |
|---|---|
| 构建 | **Vite 8** |
| 样式 | **Tailwind CSS v3**（构建时编译）+ 自定义 `app.css` |
| 脚本 | 原生 **JavaScript ES Modules**（20 个模块，无框架） |
| 图表 | **Chart.js 4.5**（本地自托管于 `public/libs/`） |
| 图标 | **Font Awesome Free 6.4**（本地自托管） |
| AI 洞察（可选） | 直接 `fetch` 调用 **OpenAI 兼容**接口，**不引入任何 SDK 或外部静态资源** |
| 存储 | **IndexedDB** 为主，**localStorage** 兜底 |
| 加密 | **Web Crypto API**：本地数据 AES-GCM；云端同步 PBKDF2 派生密钥 + AES-GCM |
| 部署 | GitHub Pages（`.github/workflows/deploy.yml`，push `main` 自动构建） |

## 使用方法

### 打卡

1. 底部导航点「打卡」（或直接进首页）
2. 若要补充地点/备注/时间，先点右下角「补充记录」填好
3. 点中央大按钮完成打卡；打卡成功后按钮会变为已打卡状态

### 查看与管理历史

1. 底部导航点「历史」
2. 顶部搜索框可按地点或备注搜索；点「筛选」可设日期范围
3. 点记录右侧铅笔图标可就地编辑，点垃圾桶或**左滑**可删除（4 秒内可撤销）

### 查看分析

1. 底部导航点「统计」
2. 查看平均间隔、本周次数、常用地点、连续天数与规律洞察
3. 切换趋势图时间范围；**点图表上的某一天**会跳回历史页并筛出当天记录
4. 页面最底部是「AI 洞察」——默认未启用。想用就去设置里开启并填好服务商与密钥，回来点「生成洞察」

### 开启 AI 洞察

1. 点右上角齿轮 → 「AI 洞察」区块 → 勾选「启用 AI 洞察」
2. 选一个服务商（会自动填好服务地址与模型，可自行修改），填入 API Key
   - 不确定模型名？点「读取可用模型」从你的账号里拉一份真实列表（该请求只读模型列表，不产生费用）
3. 点「保存设置」，回到统计页点「生成洞察」
4. 首次使用会弹出知情同意，逐条列出**发送到哪个域名**、**模型**、**会发哪些字段**、**不会发什么**；同意后才发送，且同意只对当前域名生效
5. 生成结果会缓存到本机 —— 记录没变时再次打开会直接显示上次结果，不会重复请求

### 数据管理（设置抽屉）

点右上角齿轮图标：

- **主题**：浅色 / 深色 / 跟随系统
- **AI 洞察**：开关、服务商、服务地址、模型、API Key（默认关闭，见下方「数据与隐私」）
- **坚果云同步**：填入 WebDAV 地址（必须是 `https://`）与账号密码，设定同步口令，然后上传/下载
- **导出**：JSON 或 CSV
- **导入**：选择 JSON 文件，按 id 合并
- **备份**：立即创建一份手动备份；也可从这里打开备份列表恢复

## 数据与隐私

### 记录本身：默认纯本地

- **默认纯本地**：数据只存在你自己的浏览器里（IndexedDB / localStorage），不经过任何第三方服务器。仓库里也没有任何统计、埋点或分析脚本。
- **本地加密**：落盘前使用 Web Crypto AES-GCM 加密。
- **云同步是可选且自持的**：只有你主动填写并点击上传时，加密后的数据才会被 PUT 到你**自己指定**的 WebDAV 服务器（例如坚果云）。密钥由你的同步口令经 PBKDF2 派生，服务器端拿到的只是密文。
- **关于安全上下文**：`crypto.subtle` 仅在 **HTTPS 或 localhost** 下可用。用 `file://` 直接打开页面时加密不可用，应用会明确提示而不是静默降级。
- **导出即明文**：导出的 JSON / CSV 是未加密的，请自行妥善保管。

### AI 洞察（可选功能）：会发送什么、不会发送什么

**默认关闭，且只有你主动点击才会发送。** 未开启、或开启后未点「生成洞察」时，应用不会向任何外部服务发起请求（这一点有自动化测试守着）。

- **发给谁**：你在设置里**自己指定**的服务商，走 OpenAI 兼容接口 —— DeepSeek、通义千问、Kimi、智谱 GLM、豆包、腾讯混元、硅基流动、OpenAI，或任意自定义兼容地址。密钥是你自己的，不经过本项目的任何服务器（本项目根本没有后端）。
- **发送的时机**：仅在你点击「生成洞察」并**通过知情同意**后。首次发送前会弹窗逐条列出将发送的字段与目标域名，需要你单独确认；**更换服务商（域名变了）会重新征求同意**。
- **发送的内容**：只有聚合统计 —— 观察窗口、记录总次数、有记录的天数、平均／中位／最长间隔与波动、时段分布、星期分布、地点分布、性状类型分布、连续记录天数、本周与上周次数、最近每日次数、本地判定的异常信号、数据截止日期。统计页的 AI 卡片可以展开「将发送的内容」自行核对。
- **不会发送**：备注原文、精确时间戳、自定义地点名称（自定义地点一律归入「其他」）。
- **只做总结，不做自由问答**：这是刻意的设计。功能口径固定在「把已算好的统计讲成人话」，不需要你输入任何额外文字，也就不会因为随手输入而把更多个人信息带出去。
- **模型只做措辞，不做计算**：所有数字都由本地算好后注入，prompt 明令「不得引入给定数据之外的数字或结论」。
- **密钥只在本机**：API Key 随设置一起本地加密存储，**不会**写入导出的 JSON/CSV，也**不会**随坚果云同步外传。换设备需要重新填写。它等同于你账号的调用权限，建议使用单独的、额度受限的密钥；本地加密只是提高门槛，并非绝对安全。
- **结果缓存在本机**：生成结果按「摘要哈希 + 服务商 + 模型」缓存到 IndexedDB，记录没变时不重复请求，省下不必要的费用。
- **不是医疗建议**：模型输出仅供参考，不构成医疗建议，不能替代医生的判断。
- **境外服务商会提示数据出境**：选择 OpenAI 等境外服务时，同意弹窗会明确提示数据将传输并存储于境外。若使用自定义地址，应用无从判断其属地，会提示你自行确认。

## 浏览器兼容性

| 浏览器 | 最低版本 |
|---|---|
| Chrome / Edge | **108+** |
| Safari (iOS / macOS) | **15.4+** |
| Firefox | **110+** |

门槛主要来自：`?.` / `??`（Chrome 80+）、`100dvh`（Chrome 108+ / Safari 15.4+）、`crypto.subtle`（需安全上下文）。旧版浏览器可能能打开页面但功能不完整。

## 开发说明

### 环境准备

```bash
npm install
```

### 本地开发（热更新）

```bash
npm run dev
```

默认地址 `http://localhost:5173`（localhost 属安全上下文，加密功能可用）。

### 构建与预览

```bash
npm run build      # 产物输出到 dist/
npm run preview    # 本地预览构建产物
```

### 部署

推送到 `main` 分支即触发 GitHub Actions 自动构建并发布到 GitHub Pages，无需手动操作。

### 代码修改指引

- 页面结构：`index.html`
- 样式：`src/css/app.css`；Tailwind 主题与调色板：`tailwind.config.js`
- 逻辑：按职责修改 `src/js/` 下对应模块，入口与初始化顺序在 `src/js/app.js`
